## CFP（登壇者公募）受付開始のお知らせ

フロントエンドカンファレンス福岡 2026 の一般 CFP（登壇者公募）の受付を、本日 2026 年 5 月 11 日（月）より開始いたしました。応募方法・受付期間・お問い合わせ窓口についてお知らせします。

### 募集概要

本カンファレンスは「未来のフロントエンドと徹底的に向き合う」をテーマに、各技術分野のエキスパートが集い、深く語り、対話する場として開催いたします。

LT は実施せず、**1 セッション 45〜60 分（AMA を含む）の分野別セッションを 3 トラック並行**で構成する予定です。登壇言語は日本語または英語を選択いただけます（同時通訳はありません）。

主な発表カテゴリは以下を想定しております。

- CSS
- Accessibility
- HTML
- Web API
- Performance
- Ecosystem / Tooling
- Design & Engineering
- Architecture
- Testing
- Web Standards

上記カテゴリ以外でも、Web フロントエンドに関連する内容を広く歓迎いたします。

### 応募方法

ご応募は GitHub Issue からお願いいたします。下記テンプレートより新規プロポーザルを Issue として作成してください。

- [一般応募テンプレート（Proposal_General.yml）](https://github.com/fec-fukuoka/frontend-conf.fukuoka.jp/issues/new?template=Proposal_General.yml)

提出後の確認・レビュー・採択までの流れにつきましては、[Wiki の Call for Proposals Workflow](https://github.com/fec-fukuoka/frontend-conf.fukuoka.jp/wiki/Call-for-Proposals-Workflow) をご確認ください。テンプレートの記入内容に不足がある場合は、コメントでフィードバックをお送りいたします。

### 登壇に関する詳細情報

登壇に関する詳細な情報は、[Speaker Info Dock](https://github.com/fec-fukuoka/frontend-conf.fukuoka.jp/wiki/Speaker-Info-Dock) にまとめております。ご応募前にご一読いただけますと幸いです。主な内容は以下のとおりです。

- セッション時間: 1 枠 45〜60 分（AMA を含む）
- タイトル・概要の提出目安: トーク時に最も話したい内容を伝えていただくため、プロポーザルの Issue ・内容自体は、登壇直前まで編集いただいて構いません。ただし、チケット販売開始（2026 年 7 月 1 日予定）までに、公式サイト掲載用のタイトルと概要の仮確定をお願いしております。（選考のため、公募スピーカーの方には、提出時に内容を確定していただくことをお勧めします）
- 録画・アーカイブ公開: 応募時にご承諾いただいた方のセッションのみ、録画・アーカイブ公開を予定しております。スライド資料の公開義務はありません

### 今後のスケジュール

現時点で予定しているスピーカー関連のスケジュールは以下のとおりです。

- CFP 受付開始: 2026年5月11日（月）
- CFP 募集終了: 2026年6月19日（金）
- CFP 採択結果発表: 2026年6月中（予定）
- 当日: 2026年9月12日（土）
