Reactは、フロントエンド領域における代表的なUIライブラリの一つです。Reactは、あるべきDOMの姿を宣言的に記述するという意味での宣言的UIを普及させました。しかし今、Reactの宣言的UIはそれだけに留まらず、UX全体を最適化するための包括的な概念へと進化しています。このセッションでは、モダンなReactアプリケーションを設計する方法について語り尽くします。

React is one of the most prominent UI libraries in the frontend landscape. It popularized declarative UI, meaning declaratively describing the DOM as it should be. Today, however, React's notion of declarative UI has grown beyond that, evolving into a comprehensive approach for optimizing the entire user experience. In this session, we will dive deep into how to architect modern React applications.
